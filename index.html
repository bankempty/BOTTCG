      📊 ค่า Tiebreak คืออะไร?

      1. POINTS (คะแนนรวม)

      ชนะ = 3 แต้ม / เสมอ = 1 แต้ม / แพ้ = 0 แต้ม

      2. OMWP% (Opponent Match Win %)

      อัตราการชนะของคู่แข่งที่เราเคยเจอ ยิ่งเจอสายแข็ง ค่านี้จะยิ่งสูงขึ้น

      3. OOMWP% (Opponents' Opponent Match Win %)

      อัตราการชนะของคู่แข่งของคู่แข่งเรา ใช้เป็นตัวตัดสินขั้นสุดท้าย

      ★ GWP% (Game Win % — เฉพาะ Bo3)

      เปอร์เซ็นต์เกมที่ชนะในทุก match เช่น ชนะ 2-0 และ 2-1 → gameWins=4, gameLosses=1 → GWP = 80%
      ใช้เป็น tiebreaker ลำดับ 3 (หลัง OMWP%) แทน OOMWP% ในโหมด Bo3
