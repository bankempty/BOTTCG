      📊 ค่า Tiebreak คืออะไร?

      1. POINTS (คะแนนรวม)

      ชนะ = 3 แต้ม / เสมอ = 1 แต้ม / แพ้ = 0 แต้ม

      2. OMWP% (Opponent Match Win %)

      อัตราการชนะของ "คู่แข่งที่เราเคยเจอมาทั้งหมด"
      ยิ่งเราเจอคู่แข่งสายแข็ง ค่านี้จะยิ่งสูงขึ้น ใช้ตัดสินกรณีคะแนนเท่ากัน

      3. OOMWP% (Opponents' Opponent Match Win %)

      อัตราการชนะของ "คู่แข่งของคู่แข่งเรา"
      ใช้เป็นตัวตัดสินขั้นสุดท้าย หากทั้ง Points และ OMWP% เท่ากัน
